# api_keys/

Generated by `npm run seed:technician -- "Name"` (see `scripts/create-technician.js`). Each file
here is named after the technician and its **entire content is the raw API key, nothing else** —
the exact same format `Luxtronic-PCTools-Client`'s `ApiKeyProvider` expects (see that repo's
`apikey.example.txt`). That means provisioning a new technician is: run the seed script, then copy
the resulting file here straight onto the technician's PC and rename it to `apikey.txt` next to the
client executable — no reformatting, no quotes, no trimming needed.

**These files are secrets and are git-ignored** (`.gitignore` excludes everything in this folder
except this README) — the server only ever stores a SHA-256 hash of each key (CONTRACT.md §1), so
this folder is the *only* place the raw key exists after it's issued. If a file here is lost, there
is no way to recover the key from the database — provision a new technician instead (and revoke the
old one by deleting its `technicians` row, or add a `revoke` action if that becomes a real need).
